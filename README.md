# amazon_ui_clone



A clean, responsive static clone of the Amazon homepage built using **HTML5** and **CSS3**. This project replicates the core user interface of Amazon, including the navbar, hero banner, product grid cards, and footer sections.

## ✨ Features

- **Header & Navigation**: Replicates Amazon's navigation bar, logo, search bar, sign-in, and cart section.
- **Hero Banner**: Displays the main promotional hero banner image.
- **Product Display**: Grid layout displaying product cards with image assets, titles, and shop links.
- **Footer Section**: Features back-to-top layout along with Amazon's standard navigational footer links.
- **Responsive Design**: Basic layout structure optimized for standard desktop screens.

---

## 🛠️ Tech Stack

- **HTML5**: Markup structure for the web page elements.
- **CSS3**: Styling, layout positioning (Flexbox/Grid), and visual UI polish.
